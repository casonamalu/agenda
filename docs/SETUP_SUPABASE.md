# Lista de configuración Supabase

1. Crear proyecto.
2. Ejecutar la migración SQL.
3. Desactivar registro público de usuarios en Authentication si estuviera habilitado.
4. Crear el primer usuario en Authentication.
5. Promoverlo a Administrador mediante SQL.
6. Copiar Project URL y Publishable Key al `.env` local.
7. Desplegar `admin-user`.
8. Crear una cuenta Resend y verificar un subdominio de envío.
9. Configurar secretos de las Edge Functions.
10. Desplegar `send-email-queue`.
11. Activar `pg_cron` y `pg_net`.
12. Programar la cola y la limpieza.
13. Revisar RLS mediante una cuenta Administrador y una cuenta Vendedora.
14. Ejecutar una cita de prueba y verificar el correo.
15. Configurar respaldo y alertas del proyecto según el plan contratado.
